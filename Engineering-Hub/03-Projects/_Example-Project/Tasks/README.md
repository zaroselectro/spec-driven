# Tasks – _Example-Project

**Bewusst vorgesehener Bereich für spätere Inhalte.** Projektspezifische Aufgaben liegen hier, sobald sie angelegt sind.

## Verfahren

- Gleiche Felder und gleicher Statusablauf wie in [[05-Tasks/README]]: `backlog → in-progress → review → done`, realisiert über Unterordner in diesem Verzeichnis (anlegen nach Bedarf).
- Vorlage: [[07-Templates/task-template]].
- IDs mit Projektkürzel, z. B. `EXMP-BE-001` (Kürzel ist Beispiel).

## Wann hier, wann in `05-Tasks/`?

| Ort | Verwendung |
| --- | --- |
| `03-Projects/<projekt>/Tasks/` | Aufgabe braucht Projektkontext (Anforderungen, ADRs, Projektregeln) |
| `05-Tasks/` | Aufgabe ohne Projektkontext bzw. Demonstrations-/Sammelaufgabe |

Die Statusordner werden erst angelegt, wenn die erste Aufgabe existiert – leerer Bestand ist hier bewusst vorgesehen.
