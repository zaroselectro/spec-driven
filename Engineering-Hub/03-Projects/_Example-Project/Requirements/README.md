# Requirements – _Example-Project

**Bewusst vorgesehener Bereich für spätere Inhalte.** Dieser Ordner enthält aktuell keine Anforderungen, weil das Demonstrationsprojekt keine realen besitzt.

## Was hierher gehört

- Bestätigte Anforderungen mit Quelle (Wer hat sie wann bestätigt?).
- Akzeptanzkriterien, die sich prüfen lassen.
- Nicht-Ziele (was bewusst nicht gebaut wird).
- Annahmen – ausdrücklich als Annahme gekennzeichnet, mit dem Punkt der Bestätigung.

## Regeln

- **MUSS** Keine erfundenen Anforderungen. Platzhalter bleiben Platzhalter, bis sie bestätigt sind.
- **MUSS** Änderungen an bestätigten Anforderungen werden nachvollziehbar (Versionsvermerk oder Datum mit Begründung).
- **SOLLTE** Kurze, prüfbare Formulierung („akzeptiert, wenn …“) statt Prosa.
- **SOLLTE** Verweise auf betroffene Standards und ADRs, damit Umsetzende den Kontext sofort finden.
